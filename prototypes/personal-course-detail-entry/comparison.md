# 授業詳細導線 UI 比較

## 比較結果

| 観点 | A 情報アイコン | B 「詳細」ボタン | C 授業名リンク |
| --- | --- | --- | --- |
| カードのコンパクトさ | 高い。高さは現行相当 | 高さは維持できるが右側の占有幅が最大 | 最も高い。追加部品なし |
| 授業名の表示領域 | 状態表示に加えて44px分狭くなる | 「詳細」と状態表示で最も狭い | 最も広い |
| 詳細操作の発見しやすさ | 中。ⓘの意味を知っている必要がある | 高い。文字で目的が明確 | 中。リンク表現を見落とす可能性がある |
| 履修選択との区別 | 高い。独立した操作領域 | 高い。独立した操作領域 | 中。タイトルと余白で動作が異なる |
| スマートフォンの押しやすさ | 44px領域で確保 | 50px×36px以上で確保 | 長いタイトルは押しやすいが短いタイトルは領域が小さい |
| 状態表示との干渉 | 操作と状態のアイコンが隣接する | 文字ボタンと状態アイコンで区別しやすい | 状態アイコンから十分離れる |
| 多数候補での視覚密度 | 低い | 「詳細」が反復してやや高い | 低い |
| キーボード・読み上げ | 独立buttonとaria-labelで明確 | 独立buttonと可視テキストで最も明確 | 独立buttonだがクリック領域の説明が必要 |
| 現行B案との統一感 | 高い | 中〜高 | 高いがタイトルのリンク表現が新しい |

## 客観的に確認できる点

- 3案ともカード本体と詳細操作を別の `button` とし、buttonの入れ子を避けている。
- 詳細操作では `preventDefault()` と `stopPropagation()` を行い、履修状態を変更しない。
- A案のアイコン操作領域は44px、B案は50px×36px以上を確保している。
- モーダルを閉じると詳細操作へフォーカスを戻し、曜日・時限・履修状態を維持する。
- PCは2列、390pxでは1列となり、3案比較列もスマートフォンでは縦に並ぶ。
- 必修、選択済み、競合、未選択の状態は色だけでなくアイコンと読み上げ名でも区別する。

## デザイン上の好み・判断が必要な点

- A案のⓘを十分直感的とみなすか。
- B案で多数の「詳細」が並ぶ視覚密度を許容するか。
- C案の「授業名とカード余白で動作が異なる」学習コストを許容するか。
- 詳細を頻繁に確認する利用者を優先するか、カードの静かさを優先するか。

## 暫定推奨

学校で幅広い学生が初見で利用する前提では、**B案の「詳細」ボタン方式**を暫定推奨とする。A案より視覚密度は上がるが、詳細と履修選択の操作目的が文字で明確で、状態アイコンとも意味を混同しにくい。カード高さを増やさず、短い文言に限定すれば現行B案の密度を大きく損なわない。

正式採用はHuman review後に決定し、本番へはまだ反映しない。
