# ClassView 管理ツール 操作マニュアル

このマニュアルは、学校職員がClassViewの授業情報を登録・編集し、公開するためのものです。通常の作業でプログラムやデータファイルを直接操作する必要はありません。

## 1. ClassView管理ツールを起動する

1. デスクトップの「ClassView管理ツール」をダブルクリックします。
2. ブラウザに「ClassView 管理ツール」が表示されるまで待ちます。
3. 「現在の状態」に大きな問題が表示されていないことを確認します。

起動時に公開サイトの最新状態を自動確認します。別の場所で更新されており、このPCに未公開の変更がない場合は、安全に取得できるときだけ最新状態へ更新します。

## 2. 新しい授業を登録する

1. 管理ホームで「新しい授業を登録」を押します。
2. シラバスPDF、掲載ページ、授業IDを入力します。
3. 画面の案内に従い、ChatGPTで授業情報の下書きを作ります。
4. 下書きを管理ツールへ貼り付け、内容を確認・修正します。
5. AI下書き提案がある場合は、各項目で「採用」「修正して採用」「使用しない」を選びます。
6. 「編集内容を最終検証」を押します。
7. 問題がなければ「授業を保存」を押します。

保存しただけでは公開サイトは更新されません。管理ホームへ戻り、未公開の変更を確認してください。

## 3. 授業を編集する

1. 管理ホームで「授業を管理」を押します。
2. 授業名、年度、講師名などで対象授業を検索します。
3. 「編集」を押します。
4. 必要な項目を修正し、右側または下側のプレビューと変更点を確認します。
5. 「変更を保存」を押します。

授業IDは通常変更できません。年度を更新するときは「編集」ではなく「次年度へ引き継ぐ」を使用してください。

## 4. 次年度へ引き継ぐ

1. 対象授業の「次年度へ引き継ぐ」を押します。
2. 新年度と新しい授業IDの候補を確認します。
3. 講師、概要、授業回など、変更された部分だけを修正します。
4. 変更点を確認し、「新年度版を追加」を押します。

前年度版は削除・上書きされず、そのまま残ります。

## 5. 授業をアーカイブする

1. 公開を終了する授業の「アーカイブ」を押します。
2. 授業名、年度、IDを確認します。
3. 「アーカイブ」を押します。

アーカイブした授業は公開サイトから外れますが、管理データには残ります。「アーカイブ」タブから公開中へ戻せます。

「完全削除」は、テスト登録や明らかな重複など、本当に不要な授業だけに使用してください。削除前には確認画面が表示され、バックアップも自動作成されます。

## 6. 変更内容を確認する

1. 画面上部の「管理ホーム」を押します。
2. 「未公開の変更」を確認します。
3. 授業名と「年度版を追加」「講師名を変更」「アーカイブ」などの内容が意図どおりか確認します。

間違いがある場合は、公開せずに「授業を管理」へ戻って修正してください。

## 7. ClassViewへ公開する

1. 未公開の変更を確認します。
2. 「ClassViewへ公開」を押します。
3. 「ClassViewへ公開しました」と表示されるまで画面を閉じずに待ちます。

授業を保存した直後に自動公開されることはありません。必ず内容を確認してから公開してください。

## 8. 公開サイトを確認する

1. 公開完了後の「公開サイトを開く」を押します。
2. 反映まで数分かかる場合は、少し待ってからページを再読み込みします。
3. 授業一覧と授業詳細を確認します。

## 9. エラーが出た場合

- 「インターネットに接続できません」：PCのインターネット接続を確認し、「最新状態を確認」を押します。
- 「公開サービスへのログインが必要です」：「公開サービスへ再接続」を押し、表示された案内に従います。
- 「公開サイト側に新しい変更があります」：公開を繰り返さず、管理担当者へ連絡してください。
- 「授業データに入力上の問題があります」：直前に編集した授業を開き、入力内容を確認してください。

管理担当者へ連絡するときは、「診断情報をコピー」を押して、コピーされた内容を一緒に送ってください。診断情報にパスワードやログイン情報は含まれません。

## 10. 終了する

1. 保存または公開処理が終わっていることを確認します。
2. 画面上部の「終了」を押します。
3. 「ClassView管理ツールを終了しました」と表示されたらブラウザを閉じます。

ブラウザのタブを閉じるだけでは、管理ツールが終了しない場合があります。通常は「終了」ボタンを使用してください。
